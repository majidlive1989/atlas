# @atlas/kernel

Pino emits redacted structured logs, OpenTelemetry supplies trace API hooks, Zod validates options and migration declarations, and `semver` resolves plugin dependency and engine ranges. Kernel hosts the typed service container, lifecycle, options and trusted plugin manager.

The named entry point is `src/index.ts`. Run `pnpm build` and `pnpm test` in this workspace or from the repository root.
