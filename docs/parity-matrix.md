# WordPress and WooCommerce parity matrix

The matrix assigns owners and verification milestones. Implemented marks delivered functionality and partial marks the Phase 1 foundation. **Planned** preserves the user outcome. **Replaced** assigns a deliberate future alternative. Both statuses describe roadmapped work. The logic paths name the studies that the owning phases must complete before implementation using the [logic template](logic/_template.md). Owners are workspace names. Some milestones start earlier and reach their acceptance gate in the listed phase.
