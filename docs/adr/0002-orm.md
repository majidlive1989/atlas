# ADR 0002 · PostgreSQL and Drizzle

Status: accepted for the target architecture.

## Context

Tenant isolation, transactional outbox writes, stock reservations and schema review need SQL-level control.

## Decision

Use Drizzle with PostgreSQL and versioned, reviewed SQL. Keep core and plugin ledgers separate and validate plugin namespaces. Use parameterized SQL for features Drizzle cannot represent directly.

## Alternatives considered

A generic document database makes relational integrity and reporting harder. Heavier ORM runtimes can obscure lock and query behavior.

## Consequences

Exercise migrations from previous versions against real Postgres. Require explicit recovery for irreversible schema changes.
