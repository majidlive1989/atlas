# ADR 0006 · ICU catalogs and Intl

Status: accepted for the target architecture.

## Context

The same feature must support multiple locales, RTL, plurals and locale-specific formatting.

## Decision

Use ICU MessageFormat in versioned owner namespaces. Lazy-load by locale and namespace, fall back through language and site defaults, and use Intl for text-adjacent formatting. Locale profile and direction come from the selected catalog.

## Alternatives considered

Scattered literals cannot be checked for coverage. Copying PHP translation semantics would couple Atlas-native messages to the legacy runtime.

## Consequences

Validate placeholders and fallback chains in CI. Keep identifiers and API error codes stable when their localized presentation changes.
